## v0.2.1 — 그리드 정렬 개선

### 개선

- **중앙 정렬**: 그리드 크기를 어떤 값으로 바꿔도 위젯을 화면 정중앙에 맞출 수 있습니다.

## v.0.2.0 - 위젯 생성 기능 추가

- **위젯 생성**: 하단의 내비게이터의 **위젯 버튼**으로 대시보드에서 원하는 위젯을 추가하거나 삭제할 수 있습니다.

> 위젯은 앞으로도 계속 추가될 예정입니다.

---

## v0.1.0 — 설정 기능 추가

하단 내비게이터의 **설정 버튼**으로 대시보드를 원하는 대로 바꿀 수 있습니다.

### 새로운 기능

- **그리드 정렬**: 위젯을 그리드에 맞춰 정렬할지 선택하고, 그리드 크기를 조절할 수 있습니다.
- **글자 색 / 배경**: 기본 제공 색 10가지와 커스텀 색, 직접 올린 이미지를 배경으로 사용할 수 있습니다.
- **웹 사이트 열기 방식**: 링크를 `새 탭` 또는 `현재 탭`에서 열도록 지정할 수 있습니다.
- **저장소**: 외부 API 위젯에 필요한 토큰을 한 곳에서 관리합니다.

### 개선

1. 화면 크기가 바뀌어도 위젯 배치가 유지됩니다.
2. 설정은 저장 즉시 반영되며 새로고침이 필요 없습니다.

> 자세한 사용법은 [도움말 문서](https://example.com)에서 확인하세요.
