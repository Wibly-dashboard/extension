# v1.1.0 - 반응형 레이아웃 지원 & 위젯 추가 방식 변경

## `새로운 기능`

- **반응형 레이아웃**: 화면 크기에 맞춰 위젯의 크기와 위치가 자동으로 조정됩니다.
  - 고해상도 화면(OS 배율)에서도 위젯이 과하게 작아지지 않습니다.
  - 화면 크기가 바뀌어도 위젯의 중앙·끝 정렬이 유지됩니다.
  - 화면이 좁아져 위젯이 겹치면 가장 가까운 빈자리로 옮겨 표시합니다.
- **위젯 추가 방식 변경**: 위젯 라이브러리에서 추가하면 편집 창이 먼저 열리고, 설정 후 대시보드에 배치됩니다.
- **빠른 링크 위젯**: 링크를 입력해야 추가할 수 있으며, 올바르지 않은 주소는 안내 문구로 알려줍니다.
  - 아이콘을 아직 불러오지 못했다면 사이트의 기본 아이콘(파비콘)을 대신 표시합니다.
- **Spotify 위젯**: 새로운 배경 스타일 `variant`가 추가되었습니다.

## `개선`

- 새로 추가한 위젯이 다른 위젯과 겹치지 않는 빈자리에 놓입니다. 그리드와 위젯 간격 설정도 지키며, 여러 개를 연달아 추가해도 서로 겹치지 않습니다.
- 위젯을 배치할 때 주변 위젯과의 간격에 맞춰 자연스럽게 붙도록 개선했습니다.
- 화면 크기에 맞춰 하단 내비게이션, 위젯 라이브러리, 위젯 편집, 설정 창의 크기와 여백을 조정했습니다.
  - 좁은 화면에서는 설정 탭을 좌우로 넘겨 볼 수 있습니다.
- 이전 버전에서 배치해 둔 위젯 위치는 업데이트 후에도 그대로 유지됩니다.

## `버그 수정`

- 좁은 화면에서 설정 항목 제목이 한 글자씩 줄바꿈되던 문제를 수정했습니다.
