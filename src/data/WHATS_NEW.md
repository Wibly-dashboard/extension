## v0.3.2 — Spotify 위젯 꾸미기

### 새로운 기능

- **배경 스타일 선택**: Spotify 위젯을 우클릭한 뒤 편집(연필) 버튼을 누르면 배경 스타일을 `glass`, `ghost`, `material` 중에서 고를 수 있습니다. 고른 스타일은 바로 반영되고 저장됩니다.
- **앨범 색상 배경**: `material` 스타일에서는 재생 중인 곡의 앨범 커버 색이 위젯 배경에 은은하게 입혀지고, 곡이 바뀌면 색도 부드럽게 바뀝니다.

## v0.2.2 — Spotify 연결 개선

### 새로운 기능

- **Spotify 로그인**: `설정 > 저장소 > Spotify`에서 **Spotify 로그인** 버튼으로 바로 연결할 수 있습니다.
- **토큰 직접 입력**: 직접 발급받은 Refresh Token(Client ID / Client Secret 포함)을 입력해 연결할 수도 있습니다.
- **토큰 기한 알림**: Refresh Token 기한이 남거나 지나면 저장소와 위젯의 Spotify 로고 옆에 표시됩니다.

### 개선

- **자동 재발급**: 액세스 토큰이 만료되면 자동으로 새로 발급받아, 1시간마다 토큰을 다시 입력하지 않아도 됩니다.
- **오류 안내**: 토큰이 잘못됐는지, 기한이 지났는지, Client ID/Secret이 틀렸는지 위젯에서 구분해 알려줍니다.

## v0.1.0 — 설정 기능 추가

하단 내비게이터의 **설정 버튼**으로 대시보드를 원하는 대로 바꿀 수 있습니다.

### 새로운 기능

- **그리드 정렬**: 위젯을 그리드에 맞춰 정렬할지 선택하고, 그리드 크기를 조절할 수 있습니다.
- **글자 색 / 배경**: 기본 제공 색 10가지와 커스텀 색, 직접 올린 이미지를 배경으로 사용할 수 있습니다.
- **웹 사이트 열기 방식**: 링크를 `새 탭` 또는 `현재 탭`에서 열도록 지정할 수 있습니다.
- **저장소**: 외부 API 위젯에 필요한 토큰을 한 곳에서 관리합니다.

### 개선

1. 화면 크기가 바뀌어도 위젯 배치가 유지됩니다.
2. 설정은 저장 즉시 반영되며 새로고침이 필요 없습니다.

> 자세한 사용법은 [도움말 문서](https://example.com)에서 확인하세요.
